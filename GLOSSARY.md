# Traveled

Traveled organizes shared travel memories around trips and groups.

## Language

**Photo**:
An image associated with a trip as a travel memory.
_Avoid_: Upload, file (when referring to the trip memory itself)

**Photo submission**:
A user's request to add one selected image to a trip. A retry continues the same submission; deliberately submitting the image again creates a new submission.
_Avoid_: Duplicate photo (when referring to a repeated attempt on the same submission)

**Quarantined photo**:
A submitted image withheld from trip members while it awaits moderation or publication.
_Avoid_: Published photo, shared photo

**Published photo**:
An approved photo available to authorized members of its trip's group.
_Avoid_: Uploaded photo (when availability to trip members is meant)
